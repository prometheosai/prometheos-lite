# Reproducible, hash-verified Python environment for the local CI checks.
#
# `scripts/local_ci.py` runs the core suite with an interpreter on PATH (`python`).
# Every Python check it invokes is stdlib-only except the harness catalog schema
# validator (`scripts/validate_harness_catalog.py`), which imports `jsonschema`
# and fails closed without it.
#
# This file pins the FULL transitive closure of `jsonschema==4.26.0` to exact
# versions with SHA-256 integrity hashes, for the actual supported platform of
# this repository: Windows x86_64, CPython 3.14 (the interpreter used by the
# recorded core-suite runs). `pip install --require-hashes` enforces them.
# On any other platform, installation FAILS LOUDLY (it does not silently fetch
# an unpinned artifact) until the matching wheels/hashes are appended here.
#
# Installation is deliberately a MANUAL, SEPARATE, TRUSTED PREFLIGHT step —
# it is never run implicitly by `local_ci.py`, never from a compromised
# checkout, and never fetches anything beyond what the hashes below pin.
# Use the isolated venv under the (gitignored) `.local-ci/` directory:
#
#     scripts/local_ci_python_env.sh
#     <repo>/.local-ci/python-env/Scripts/python.exe scripts/local_ci.py run --suite core   (Windows)
#     <repo>/.local-ci/python-env/bin/python        scripts/local_ci.py run --suite core     (POSIX)
#
# Selecting the installed interpreter on PATH is what makes the core suite
# use the hash-verified environment; `local_ci.py` itself performs no installs.
